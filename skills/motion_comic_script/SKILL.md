# 漫画解说 · 剧本生成（悬疑快切模板）

为 `production_mode: motion_comic` 项目生成**第三人称快切解说稿**。

## 默认模板

**悬疑灵异 · 第三人称快切解说** — 参照抖音/B站爆款叙事实录风（算命救人、多线交叉、倒计时压迫）。

## 叙事人称

- 主人公：**我**
- 其他人物：第三人称（他/她/名字）
- 禁止通篇第二人称「你」（除非用户明确要求体验人生体）

## 句读与排版

| 规则 | 说明 |
|------|------|
| 一句一行 | TTS 一镜一句 |
| 单句长度 | 8～18 字为主，最长 22 字 |
| 段间空行 | 换场景 / 换平行叙事线 |
| 对话 | 嵌入叙述（「xx说道」），禁止「角色名：台词」独占一行 |

## 九段剧情骨架

1. **反差钩子** — 日常 + 惊人之语
2. **预言升级** — 掐指推算，信息加码
3. **拉锯不信** — 犹豫，补家庭细节
4. **转折相信** — 打电话 / 报警
5. **平行危机线A** — 受害方：电话、敲门、险开门
6. **平行危机线B** — 主人公赶救、灵力限制、倒计时
7. **倒计时压迫** — 贯穿全文（「最多还有X分钟」）
8. **高潮解局** — 出手制服 / 警察赶到
9. **余韵收尾** — 谢礼、人设、下一卦钩子

## 片头 hook

```
本期故事：大学生算卦救卤肉店，连环杀人犯破门而入。
```

## 格式示例（节选）

```
卤肉店老板看我太过可怜
好心给我一个肉夹馍
我却转头就对他说
你儿子快死了
看着两人惊悚的目光
我又掐指一算
到你女儿也要死了

刘翠兰有点摇摆不定
看了看丈夫
又看了看我
小闺女才4岁
儿子18岁

陈家佑掏出自己的手机
一边拨打着儿子的电话
一边道
小伙子，我信你一次
宁可信其有，不可信其无
```

## 篇幅

默认 3000～8000 汉字；用户指定时严格遵循。

## 制作约束

- 纯文本，不要 markdown、不要 `**`（强调在旁白分镜步骤标注）
- 用户给小说长文时：**拆短句、嵌对话、按九段骨架重组**
- 画风：国漫条漫插画；合成：1～2 镜一图 + 上下运镜
