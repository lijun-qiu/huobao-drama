# 漫画解说 · 剧本生成（悬疑快切模板）

为 `production_mode: motion_comic` 项目生成**第三人称快切解说稿**（对话为主）。

## 默认模板

**悬疑灵异 · 第三人称快切解说** — 参照抖音/B站爆款叙事实录风（算命救人、多线交叉、倒计时压迫）。

## 台词配比（硬性）

- 目标（按正文行数，不含片头「剧中：」）：**旁白 ≤35% / 对白 ≥65%**（理想约旁白 30% / 对白 70%）
- 对白 = `我：` / `角色名：` 等直接引语成行
- 冲突、对峙、救人、打电话、质问：优先角色开口，少用旁白转述说话
- **禁止空桥接旁白**：如「直接对他说」「我却转头就对他说」——删掉桥接，下一行直接写说话人台词
- 喊叫/怒吼/电话里的话：一律写成「说话人：台词」
- **交稿前自检**：数旁白行与对白行；旁白 >35% 必须继续改写后再输出
- 注意：这不是旁白解说主导稿；角色必须大量开口

## 叙事人称

- 主人公：**我**（直接引语行写 `我：台词`）
- 叙述：**旁白：**
- 其他人物：第三人称名字（`林小雅：`、`民警：` 等）
- 片头 hook：`剧中：本期故事：…`
- 禁止通篇第二人称「你」（除非用户明确要求体验人生体）

## 句读与排版

| 规则 | 说明 |
|------|------|
| 一句一行 | TTS 一镜一句 |
| 说话人前缀 | **每行** `说话人：台词`，禁止裸句 |
| 单句长度 | 8～18 字为主，最长 22 字 |
| 段间空行 | 换场景 / 换平行叙事线 |
| 对白 | 角色直接引语单独一行，写清说话人；禁止「xx说道」嵌在旁白里 |

## 九段剧情骨架

1. **反差钩子** — 日常 + 惊人之语（惊人之语须「我：」对白）
2. **预言升级** — 掐指推算，信息加码（震惊/反驳用对白）
3. **拉锯不信** — 犹豫，补家庭细节（细节尽量角色说出）
4. **转折相信** — 打电话 / 报警（表态与电话内容用对白）
5. **平行危机线A** — 受害方：电话、敲门、险开门
6. **平行危机线B** — 主人公赶救、灵力限制、倒计时
7. **倒计时压迫** — 贯穿全文（「最多还有X分钟」；催促喊话用对白）
8. **高潮解局** — 出手制服 / 警察赶到
9. **余韵收尾** — 谢礼、人设；可留剧情悬念，**禁止**关注/下期预告引流

## 片头 hook

```
剧中：本期故事：大学生算卦救卤肉店，连环杀人犯破门而入。
```

## 格式示例（节选，旁白约三成 / 对白约七成）

```
剧中：本期故事：大学生算卦救卤肉店，连环杀人犯破门而入。

旁白：卤肉店老板好心给我肉夹馍
我：你儿子快死了
刘翠兰：你胡说什么呢
陈家佑：小伙子别乱讲话
我：到你女儿也要死了
旁白：两人目光瞬间惊悚
刘翠兰：小闺女才4岁啊
刘翠兰：儿子刚考上大学
旁白：刘翠兰看向丈夫又看向我
陈家佑：我信你一次
陈家佑：宁可信其有
旁白：陈家佑掏出手机拨号
陈家佑：儿子你快接电话
```

## 篇幅

默认 3000～8000 汉字；用户指定时严格遵循。

## 制作约束

- 纯文本，不要 markdown、不要 `**`（强调在分镜步骤标注）
- 用户给小说长文/无说话人稿时：**拆短句、补说话人前缀、叙述里的说话改成对白行、压旁白至约三成、按九段骨架重组**
- 禁止片尾：故事还没结束、下期继续、记得关注、咱们下期再见
- 画风：高对比国漫；合成：约 2～4 镜一图（按场景换图）+ 智能运镜
