# 漫画解说 · 旁白分镜

为 `production_mode: motion_comic` 项目把解说稿拆成可 TTS 配音、可出电影感日系插画的镜头。

## 核心理念

**一句旁白一镜**（配音粒度），与解说模式相同；差异在画风（电影感日系）与合成运镜。配图按**实际画面变化**决定是否换图，勿句句切。

## 解说稿格式

```
今天体验的人生剧本是，废柴少年逆袭宗门。

你站在演武场中央，弟子们围成一圈。
三年前那个雨夜，一切从这里开始。
```

## 拆镜规则

- 片头 hook → 单独片头镜（剧中红字）
- 正文按句拆镜，自动标注 `**` 强调
- 配图：**约 2～4 镜一图**，**按场景/动作/焦点变化换图**；换人说话不强制换图；人物统一正常头身比日系审美，不写胖瘦体型词
- 合成：智能运镜（推/拉/横移等），同图整段一种运镜

## 配图 prompt 要点

- 六维结构：画风规格 / 画面主体 / 年代场景 / 核心细节动作 / 光影色调 / 镜头视角 / 质感要求
- 电影感日系：细腻线稿、柔和赛璐璐与体积感、正常头身比、16:9 横屏；禁止速度线/条漫粗黑线
- **主要配角**须引用 characters 表定妆外貌；一次性路人 inline 描述
- 单张完整电影感插画，**禁止双格**（特殊对比镜除外）

## 与素体解说差异

| 项目 | 素体解说 | 漫画解说 |
|------|---------|---------|
| 画风 | 圆头素体 | 电影感日系插画 |
| 配图密度 | 2～4 镜一图 | **约 2～4 镜一图，按画面变化换图，约 25%～40%** |
| 人物体型 | 份数档位 | **统一正常头身比日系审美** |
| 合成运镜 | 中心推/拉镜 | **智能运镜（含横移/上下）** |
| 角色配音 | 仅旁白 | 旁白为主（保留多角色音色能力） |
