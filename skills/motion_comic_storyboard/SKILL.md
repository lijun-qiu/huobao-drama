# 漫画解说 · 旁白分镜

为 `production_mode: motion_comic` 项目把解说稿拆成可 TTS 配音、可出漫画插画的镜头。

## 核心理念

**一句旁白一镜**，与素体解说模式相同；差异在画风（国漫条漫）与合成（上下运镜）。

## 解说稿格式

```
今天体验的人生剧本是，废柴少年逆袭宗门。

你站在演武场中央，弟子们围成一圈。
三年前那个雨夜，一切从这里开始。
```

## 拆镜规则

- 片头 hook → 单独片头镜（剧中红字）
- 正文按句拆镜，自动标注 `**` 强调
- 配图：**1～2 镜一图**，场景切换换图
- 合成：**上下运镜**（交替上→下 / 下→上），条漫阅读感

## 配图 prompt 要点

- 六维结构：画风规格 / 画面主体 / 年代场景 / 核心细节动作 / 光影色调 / 镜头视角 / 质感要求
- 国漫条漫：粗黑线描、平涂赛璐璐、正常头身比、16:9 横屏
- **主要配角**须引用 characters 表定妆外貌；一次性路人 inline 描述
- 单张完整漫画插画，**禁止双格**

## 与素体解说差异

| 项目 | 素体解说 | 漫画解说 |
|------|---------|---------|
| 画风 | 圆头素体 | 国漫条漫插画 |
| 配图密度 | 2～4 镜一图 | **1～2 镜一图** |
| 合成运镜 | 中心推/拉镜 | **上下运镜** |
| 角色配音 | 仅旁白 | 旁白为主（保留多角色音色能力） |
